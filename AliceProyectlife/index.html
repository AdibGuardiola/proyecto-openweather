1. El proyecto

Vais a construir una web del tiempo que pida datos reales a internet. La web le pregunta a un servidor (OpenWeather) "¿qué tiempo hace en Las Palmas?" y el servidor contesta con un JSON. Vuestro trabajo es pedir bien los datos y mostrarlos bonitos.

🎯Mínimo obligatorio

Buscador de ciudad, temperatura en °C, descripción en español, icono, humedad y viento.

🚀Para subir nota

Pronóstico de 5 días, mensajes de error y tu ubicación con el GPS del navegador.

📦Entrega

Carpeta con index.html, style.css y script.js, subida a GitHub y publicada en Netlify.

2. Antes de empezar: tu API key

  1. Crea una cuenta gratis en openweathermap.org.
  2. Entra en tu usuario → My API keys y copia la clave (32 letras y números).
  3. Paciencia: una clave nueva puede tardar hasta un par de horas en activarse. Mientras tanto la API responde 401 Invalid API key.
  4. Usaremos la versión 2.5 (gratuita). La documentación oficial: Current weather y 5 day forecast.

Así es una petición a la API

https://api.openweathermap.org/data/2.5/weather?q=Las Palmas&units=metric&lang=es&appid=TU_API_KEY
  • Servidor: a quién le preguntamos.
  • Ruta: versión 2.5 y qué queremos (weather = tiempo actual, forecast = 5 días).
  • Parámetros: después de ? y separados por &: ciudad, unidades (°C), idioma y tu clave.

💡 Truco: pega esa URL con tu clave en la barra del navegador y verás el JSON directamente.

3. Paso a paso

Haz los pasos en orden. Cada uno añade algo al anterior. Abre la consola con F12 → Console para ver lo que pasa.
